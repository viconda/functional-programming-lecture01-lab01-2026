ЗАПУСК НА ДРУГОМ КОМПЬЮТЕРЕ
Нужен Python 3.10 или новее. Команды выполняются из папки проекта.
Для самих решений внешние библиотеки не требуются:
    python -X utf8 lecture01/run_all.py
    python -X utf8 lab01/run_all.py
    python -X utf8 lab01/defense.py
Отдельное задание запускается независимо, например:
    python -X utf8 lab01/task4.py

ПОЛНАЯ ПРОВЕРКА В WINDOWS
    python -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements-dev.txt
    .venv\Scripts\python.exe -X utf8 check_lab.py
    .venv\Scripts\python.exe -X utf8 check_lecture.py
    .venv\Scripts\python.exe -m ruff check lecture01
    .venv\Scripts\python.exe -m mypy --strict lecture01

ПОЛУЧЕННЫЕ РЕЗУЛЬТАТЫ
Проверено на Python 3.12.14. В лекции 14 отдельных сценариев,
74 собственных assert; СРС 1 дополнительно выполняет 4 assert
вложенного примера. В лабораторной 104 assert в семи наборах тестов,
pytest: 7 passed. Нечистый исходный пример стипендии выполнен отдельно.
Модуль defense.py дополнительно проверяет пороги отбора 90 и 95.
Ruff и mypy не выявили ошибок в проверяемых решениях.

ПОЯСНЕНИЯ
Шкала буквенных оценок взята из опубликованной общей шкалы Satbayev
University; источник приведён в отчёте. Шкала задаётся явным аргументом.
Это буквенное отображение среднего балла учебных данных, а не полный
расчёт итоговой оценки с экзаменом и допуском.
impure_examples.py и scholarship_original.py сохраняют исследуемые
нечистые примеры преподавателя. Ограничения на чистоту относятся
к исправленным функциям; ввод и вывод остаются в оболочке.
Числа Чёрча намеренно используют именованные lambda по условию.
Проверка чистоты является эвристикой, её ограничения разобраны в отчёте.

Снимки сняты после выполнения Python в редакторе Sublime Text.
Для вставки в Word из них вырезана область результатов без изменения
содержимого. Полные исходные снимки сохранены рядом.
